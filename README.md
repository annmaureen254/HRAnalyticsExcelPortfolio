# HRAnalyticsExcelPortfolio
### PROJECT TITLE: People Analytics Dashboard: Workforce Intelligence for a Global Employer
### PREPARED BY: Ann Maureen Wangui Ngina
#### DATE 27th May 2026

This analysis was commissioned to support a workforce equity review and talent retention strategy across a 6-city global workforce. All findings are data-driven and presented for executive decision-making.

TABLE OF CONTENTS

Sheet	Name 	Contents

1	ReadMe	Project overview, authorship, and navigation guide

2	Data	876-row cleaned employee dataset with 21 original fields and 5 calculated helper columns

3	Pivot Analysis	6 pivot tables examining salary equity, education vs performance, bonus distribution, training ROI, 		promotion gaps, and workforce distribution

4	Dashboard	Interactive 1-page visual dashboard with KPI cards, 6 charts, and slicers for Department, Office Location, and 	Employee Type
	
5	Insights: Executive summary, 5 data-backed business findings with recommendations, and methodology notes
